## 📝 Descripción del Proyecto
Este proyecto es un emulador de un reproductor de música en la consola, desarrollado íntegramente en C++. El sistema permite la gestión de una lista de reproducción mediante el uso de estructuras de datos manuales (Listas Doblemente Enlazadas y Pilas), cumpliendo con la restricción de no utilizar la Standard Template Library (STL) para el almacenamiento principal. Incluye funcionalidades como carga de archivos `.txt`, modos de reproducción (aleatorio y repetición), y guardado de estado en un archivo `.cfg`.
